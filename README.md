# Personal Portfolio Website

A responsive personal portfolio website developed using **React.js and Vite** to showcase my profile, technical skills, projects, and contact information.

## About the Project

This portfolio website presents my academic background, technical skills, projects, and development journey as a B.Tech IT student. It is designed with reusable React components and a clean, user-friendly interface.

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Git and GitHub

## Features

- Personal introduction and About section
- Technical skills showcase
- Projects section
- Contact section
- Reusable React components
- Navigation using React Router
- Responsive user interface
- Component-based architecture

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/DhyaniPatel07/portfolio-24it066.git
```

**2. Open the project folder**

```bash
cd portfolio-24it066
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## Run Production Build

```bash
npm run build
```
